# SVG Pointer Trail

A recovered JavaScript / SVG experiment: thirty linked shapes follow the pointer through a spring-like chain.

## Run
Open index.html in a modern browser. No installation, dependencies, build step or server is required. Move the pointer to guide the trail. Use the keyboard-accessible Pause animation button to stop movement. Reduced-motion preferences start it paused.

## Restoration changes
Corrected pointer coordinates using the SVG screen transformation, added pause/resume and a reduced-motion default, and refreshed the responsive presentation. The original thirty-segment animation idea is preserved.

This is a learning exercise, not a production animation library. No personal data, tracking or external services are used.
